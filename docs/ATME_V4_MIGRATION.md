## Binding corrections

- ATME receives, stores, versions and reviews externally authored scripts; it does not author them.
- Every project resolves an Authoritative Narrative Source. Script-based projects use the
  approved external script as semantic authority and the user recording as timing authority.
  Audio-only and video-only projects use the user recording as both authorities; connected-AI
  transcripts/scene structures are derived indexes and never replace the recording's authority.
- Local speech processing supplies technical speech timing/alignment. The connected AI is the semantic transcription authority.
- Citation handling is deterministic provenance/schema validation, never internal research or factual verification.
- Saved approved productions must preview/render with ATME network access blocked, after dependencies and media are available.
- Preserve Caleb-derived renderer behavior and regression evidence. Only LONG_FORM_16_9 and SHORT_FORM_9_16 are output profiles.
- No internal creative provider mode, fallback, credential storage or fake-provider production path remains in the final source tree.

1. Freeze cognitive expansion; establish deterministic project state, artifact versions and explicit approvals.
2. Extract reusable validation, geometry and board compilation from mixed agent modules.
3. Add bounded ingress for brief/script/storyboard/director/timeline and local media.
4. Expose the same project service through a genuine MCP adapter and CLI; report actual capabilities.
5. Prove external-AI creation, invalid-output correction, preview and a real MP4 through MCP.
6. Complete project-oriented UI, media-first paths, both output profiles and required editing.
7. Delete obsolete internal agents/gateway/settings/prompts/dependencies/tests/docs after replacement acceptance.
8. Rebuild and test packaged zero-key startup, network-isolated render/resume, and research regressions.

No intermediate slice establishes completion of the whole migration. Do not treat an HTTP
adapter as MCP, technical alignment as semantic transcription, synthetic fixtures as original
narration acceptance, or a profile identifier as proof that portrait rendering works.
