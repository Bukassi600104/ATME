# ATME production audit and completion plan

ATME can now generate a layout and an executable timeline for a supported semantic storyboard. A narrated queue sequence has passed through the connected client, local compiler, preview and MP4 exporter. Richer productions still require externally authored executable documents for instructions outside the compiler's supported vocabulary.

It verifies the encoder checksum, installs the locked wheels in a build environment, freezes the sidecar and produces the NSIS installer. The designated release signing service and clean installation test follow the local build.

## Corrections implemented in this source checkpoint

| Correction | What was checked |
| --- | --- |
| Public v2 preview now draws the frame displayed at the requested time. Camera and paper-background previews use the same frame clock as export. | Isolated copies of both packaged QA projects were scrubbed across frame boundaries. The preview held within each displayed frame and changed across the boundary. Millisecond inspection for source animation is still available. |
| New v2 submissions identify the action when move, scale or rotate carries opacity, or fade carries a spatial destination. | Project writes and storyboard proposals reject the incompatible channels. Supported transforms and explicit nulls remain usable. Historic spatial actions retain their sampled appearance. The renderer already rejected a fade with a destination. |
| Revision requests use the edited production duration. Legacy visual proposals can be previewed using the authored board duration while a recording is still in the media bin. | A shorter supporting import leaves the full edited range selectable. Trimming the edit rejects a selection past the new end. The legacy proposal check previews an image before acceptance and preserves the project revision until the proposal is accepted. |
| The connected client can now compile just the spoken triggers of a stored v2 storyboard. | A real MCP client resolved the second occurrence, applied an offset and obtained the same result on a repeated read. The operation reuses a completed timing measurement across storyboard changes, rejects a stale edit and reports beat, action and instruction IDs on failures. On a copy of a previously measured spoken QA recording, “the” occurrence two resolved to 3.120 seconds, “each request” resolved to 0.720 seconds and “queue” was flagged at confidence 0.659 against the default 0.75. |

The speech result includes word indices, timing and plan identifiers, and lists non-speech actions separately. It counts an exact phrase within a narration scene, with occurrences numbered across scenes in recording order. Incomplete word alignment currently requires review because the alignment store can omit unmatched words. The result covers spoken anchors. Building placements, action durations, other trigger types, board state and the finished timeline remains Phase 2 work. The previously packaged 0.1.3 installer predates these corrections.
